# Phase Completion Checklist

An agent (or human) ticks these as each phase lands. A phase is **Done** only when every
box under it is `[x]` *and* the common Definition of Done holds. Update the `Status:` line as
you go (`Not started` → `In progress` → `Done`). Keep this file honest — an unchecked box on
a "Done" phase is a bug.

## Definition of Done — applies to EVERY phase

- [ ] Work committed on a feature branch; the commit/PR references the phase number
- [ ] All acceptance boxes for the phase below are checked
- [ ] Tests written and green in CI per **[TESTING.md](TESTING.md)** — unit + integration, plus
      an e2e/golden check where the phase implies one (see its per-phase "what to test" table)
- [ ] No secrets committed; `api/.env.example` updated if new env vars were introduced
- [ ] The stage doc updated if the implementation diverged from the plan
- [ ] `GET /readyz` still green (all dependencies reachable)
- [ ] No regression in the Stage 15 corpus once that harness exists
